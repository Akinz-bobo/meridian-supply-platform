# Glossary

The words used in this project, with one meaning each. Code, events, database tables and documents use these terms and no synonyms.

| Term                             | Meaning                                                                                                                               |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| **Actual**                       | Money spent: the value of goods received against a purchase order                                                                     |
| **Allocation**                   | Choosing which batch satisfies a pick, by first expired, first out                                                                    |
| **Ambient**                      | Storage at room temperature. One of the three storage classes                                                                         |
| **Available budget**             | Budget minus committed minus actual                                                                                                   |
| **Batch**                        | A quantity of one product made together, sharing a batch number and an expiry date. Also called a lot by some suppliers. We say batch |
| **Budget**                       | An amount of money for one category in one period                                                                                     |
| **Buyer**                        | The person who raises purchase orders                                                                                                 |
| **Category**                     | A grouping of products used for budgeting and reporting                                                                               |
| **Chilled**                      | Storage between 2 and 8 degrees Celsius                                                                                               |
| **Commitment**                   | Budget reserved for a purchase order that has not yet been received                                                                   |
| **Curation**                     | Turning supplier data into trusted product master data: validating, cleaning, matching and approving                                  |
| **Data steward**                 | The person responsible for the quality of the product master                                                                          |
| **Demand forecast**              | The expected sales of a product per period                                                                                            |
| **FEFO**                         | First expired, first out. The allocation rule                                                                                         |
| **Frozen**                       | Storage at or below minus 18 degrees Celsius                                                                                          |
| **Goods receipt**                | The record of a delivery arriving against a purchase order                                                                            |
| **GTIN**                         | Global Trade Item Number. The barcode number that identifies a product                                                                |
| **Lead time**                    | Days from sending a purchase order to goods arriving                                                                                  |
| **Minimum order quantity**       | The smallest quantity a supplier will accept on an order                                                                              |
| **Minimum remaining shelf life** | The days of life a batch must still have to be sold                                                                                   |
| **Movement**                     | See stock movement                                                                                                                    |
| **Pick**                         | Taking stock from a zone to fulfil an outbound order                                                                                  |
| **Product**                      | Something the distributor sells, identified by a GTIN                                                                                 |
| **Product master**               | The single approved list of products                                                                                                  |
| **Purchase order**               | A request to a supplier to deliver products at agreed prices                                                                          |
| **Quarantine**                   | Stock that exists but cannot be sold, pending inspection, recall or write-off                                                         |
| **Recall**                       | A manufacturer's instruction to withdraw a batch                                                                                      |
| **Reorder point**                | The stock level at which a product should be reordered                                                                                |
| **Replenishment proposal**       | A suggestion from the planning service to order a quantity of a product from a supplier                                               |
| **Safety stock**                 | Extra stock held to absorb uncertainty in demand and lead time                                                                        |
| **Short-dated**                  | A batch inside its minimum remaining shelf life                                                                                       |
| **Stock level**                  | The quantity of a batch in a zone, derived from movements                                                                             |
| **Stock movement**               | A recorded change in stock: receipt, transfer, pick, adjustment or write-off                                                          |
| **Storage class**                | Ambient, chilled or frozen                                                                                                            |
| **Supplier**                     | A company the distributor buys from                                                                                                   |
| **Supplier product**             | A supplier's offer of a product: their code, price, pack size, lead time and minimum order quantity                                   |
| **Warehouse**                    | A site that holds stock                                                                                                               |
| **Write-off**                    | Removing stock that can no longer be sold, with a reason                                                                              |
| **Zone**                         | An area of a warehouse with one temperature class                                                                                     |
